## Claude Code notes

- pstack loads from this repo's `.claude/settings.json` after you trust the folder. You do not install it yourself.
- Run `/pstack:setup-pstack` once to choose models that your Claude plan includes.
- This repo turns off superpowers and the Karpathy guidelines, so they do not compete with pstack.

## UI design reference

- The agreed UI look and behaviour is in `docs/design/prototypes/`. Read its `README.md` before any portal or UI work.
- `mvp-prototype.html` is the target for the November MVP. `full-prototype.html` is the Phase 2 vision.
- The prototypes use old themed names (Flint, Forge, Striker, etc.). Do not use them. The README maps them to plain names.
