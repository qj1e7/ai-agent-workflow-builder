# Sprint review and retrospective template

**For.** Rubric item 8, "sprint review and sprint retrospective", and the sprint plan and backlog of item 6. Copy this file once per sprint as `sprint-<n>-review.md` in this folder, and fill it in at the end of the sprint. For sprints 1 to 5, fill it in from memory, meeting notes, chats and [sprints.md](sprints.md), and say so at the top.

Keep it short. One page per sprint is enough. Every claim of work done should point at something an assessor can open: a pull request, an issue, a file, a CI run or a screenshot.
