# Hours log

**For.** Rubric item 16, "hours expended by each member", and item 18, "overall sprint effort to date: estimate versus actual for every member, for all sprints conducted". The monthly progress report also asks for each member's hours since the last report.

**Status.** A template. Every cell below is empty on purpose. Git does not record hours, so only each member can fill in their own. Please do not copy numbers from someone else's row or guess from pull request counts.

## How to fill it in

1. Each member fills in their own row in each sprint table, once per sprint, by the sprint's last day.
2. **Estimate** is the hours you planned for the sprint at sprint planning. If there was no planning for that sprint, write the hours you expected to spend, and mark the cell with `(late)`.
3. **Actual** is the hours you spent. Count meetings, research, design, code, tests, reviews, documents, the slides and the videos.
4. **Main work** names what the hours went to, in a few words, with pull request or issue numbers where they exist. Work outside GitHub counts the same.
5. Round to the nearest half hour.
6. The totals table at the end adds up each member's rows. Keep it in step by hand, or paste the tables into a spreadsheet.

The sprint dates are the proposed calendar in [sprints.md](sprints.md). Members are listed by role. Replace "Member 2" and the rest with names.
